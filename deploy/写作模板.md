# 怎么写一条（复制粘贴即可）

线上是静态站，没有后台。发内容有三条路：

| 方式 | 需要 | 适合 |
|---|---|---|
| A. GitHub 网页直接写 | 浏览器 | 手机、随时随刻、改错字 |
| B. 本地后台 | 电脑装 Node | 传图片、批量写 |
| C. 本地写文件 | 电脑 | 一次写很多 |

---

## A. GitHub 网页（最简单）

1. 打开 **https://github.com/oAo-o11o/myblog**
2. 点进 **`content`** → **`posts`**
3. 右上角 **Add file** → **Create new file**
4. 文件名填：`thought-2026-11-03.mdx`（日期换成今天）

### 模板 1 · 一条想法

```yaml
---
kind: thought
date: "2026-11-03"
topics: ["哲学"]
---

这里写想法。

可以分好几段，空一行就是新段落。
```

### 模板 2 · 一篇长文章

```yaml
---
kind: article
date: "2026-11-03"
title: "为什么数学的证明让人安心"
topics: ["数学", "哲学"]
---

正文从这里开始。

## 可以有小标题

也可以列清单：

- 第一点
- 第二点
```

### 模板 3 · 想法带图片（图片先传到 public/photos）

```yaml
---
kind: thought
date: "2026-11-03"
topics: ["记录"]
media: ["2026-11-03-flower.jpg"]
---

今天路过一棵树。
```

5. 拉到页面底部 → **Commit changes** → 选 **Commit directly to the `main` branch** → 点绿色按钮
6. 等 1–2 分钟（去 **Actions** 标签能看到进度）
7. 刷新网站，内容出现了

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `kind` | ✅ | `thought`（想法）或 `article`（文章） |
| `date` | ✅ | `"YYYY-MM-DD"`，带引号，决定排序 |
| `topics` | 可选 | 题目数组，会出现在侧栏和 `/topics` 页 |
| `title` | 文章必填 | 想法不需要标题 |
| `media` | 可选 | 图片/视频文件名数组，文件要先放进 `public/photos` 或 `public/videos` |

## B. 本地后台（能传图、传视频）

```powershell
cd C:\Users\YoY\Documents\deepseek-harness\default-workspace\myblog-dev
npm run dev
```

然后浏览器打开 **http://localhost:3000/admin/login**

用户名和密码在项目根目录的 `.env` 里，用这条命令看：

```powershell
Get-Content .env
```

登录后：
- **写一条** → 可以直接选「想法」还是「文章」，填题目，拖图片上传
- **概览** → 看所有内容，可编辑、可删除
- **题目** → 改题目名（会同步改所有文件的 frontmatter）
- **站点设置** → 改首页标题、题记、默认皮肤

写完 → `Ctrl+C` 停掉 → 提交到 GitHub：

```powershell
git add content public
git commit -m "post: 今天写的东西"
git push
```

⚠️ 上传的图片会直接进仓库。一张手机原图 7–8 MB，放十几张就顶到 GitHub 的 1 GB 上限。传之前压一下：

```powershell
# 需要 ImageMagick，没有的话用手机相册自带的「压缩」也行
magick input.jpg -resize 2000x2000^> -quality 82 output.jpg
```

## C. 改已有的内容 / 改错字

**GitHub 网页**：点进那个 `.mdx` 文件 → 右上角**铅笔图标** → 改 → Commit changes

**本地**：直接用记事本打开 `content\posts\xxx.mdx` 改，然后 `git add` + `commit` + `push`

---

## 删一条

GitHub 网页：点进文件 → 右上角 **⋯** → **Delete file** → Commit

本地：删掉文件 → `git add -A` → `git commit -m "del"` → `git push`

---

## 常见问题

| 问题 | 原因 |
|---|---|
| 提交后网站没变 | Actions 还在跑，等 1–2 分钟；或构建失败，去 Actions 看红叉 |
| 想法跑到「文章」里去了 | `kind` 忘了写或写错，必须是 `thought` |
| 日期不对/顺序乱 | `date` 要带引号，格式 `"2026-11-03"` |
| 图片不显示 | 文件名要和 `media` 里写的一致，且文件确实传到了 `public/photos` |
| 页面打开是 404 | 文件名里的中文/空格换成英文，例如 `thought-2026-11-03.mdx` |
