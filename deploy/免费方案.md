# 不掏钱的部署方案

## 先分清两笔钱

| 项 | 能不能省 |
|---|---|
| 服务器 | **能**，下面三个方案 |
| 域名 | 有自有域名就只剩续费（`.online` 约 ¥100–150/年）；接受免费二级域名就能全免 |
| 电费 | 用自己的设备 ≈ ¥10–20/月，严格说不是 0 |
| 时间 | 免费方案都要自己折腾，这部分省不掉 |

---

## 方案 A：旧笔记本 + Cloudflare Tunnel（0 服务器成本，已验证）

你之前就是这么干的，`shidagu.online` 现在跑通的那套。

```bash
# 机器上
sudo apt install -y nodejs npm ffmpeg
cd /opt/myblog/app && npm ci && npm run build
pm2 start deploy/ecosystem.config.js && pm2 save && pm2 startup

# 隧道（不用公网 IP、不用开端口、不用备案）
cloudflared tunnel login
cloudflared tunnel create cyberlog
cp deploy/cloudflared.yml ~/.cloudflared/config.yml   # 换 TUNNEL_UUID
cloudflared tunnel route dns cyberlog shidagu.online
sudo cloudflared service install
```

**必须处理的三个现实问题**：

```bash
# 1) 合盖不休眠
sudo sed -i 's/^#\?HandleLidSwitch=.*/HandleLidSwitch=ignore/' /etc/systemd/logind.conf
sudo systemctl restart systemd-logind

# 2) 断电恢复：BIOS 里开 "Power On after AC Loss"，pm2 startup 已帮你拉起进程
# 3) 家宽上行 10–30M，视频首访慢；画廊已用封面图，正文视频 preload=none，影响可控
```

**结论**：0 元，今天就能上，性能和稳定性取决于你家那台机器。

## 方案 B：Oracle Cloud Always Free（真免费 VPS，性能过剩）

甲骨文的「永久免费」是目前唯一能给到 **4 核 ARM / 24G 内存 / 200G 硬盘 / 10T 月流量** 的免费 VPS，跑这个博客属于大炮打蚊子。

**怎么申请**

1. 注册 Oracle Cloud 账号，地区选 **首尔 / 东京 / 新加坡 / 大阪**（离国内近）
2. 需要一张信用卡做验证（会冻结约 $1，之后退回；借记卡有时也能过）
3. 创建实例时选 **Ampere A1（ARM）**，4 OCPU / 24G，系统 **Ubuntu 22.04**
4. 拿到 IP 后直接跑 `deploy/bootstrap.sh`，剩下和付费服务器一模一样

**四个坑，先知道再上车**

- **ARM 实例经常「无容量」**：热门区域开不出来，要么换区域，要么脚本轮询抢（社区有 `oci-arm-host-capacity` 这类工具）。
- **闲置回收**：Always Free 实例长期低负载可能被回收，建议保持一点日常流量，别彻底闲置。
- **注册被拒**：国内地址 + 虚拟卡容易风控失败，失败就换卡/换邮箱再试，别死磕。
- **单点故障**：免费额度只有一份，别把唯一备份放在上面——`deploy/backup.sh` 的备份要再同步一份到本地。

**结论**：真免费、性能最好，但注册有门槛，适合愿意折腾一次的人。

## 方案 C：白嫖新用户试用，当迁移演练

阿里云 / 腾讯云轻量都有新用户 1 个月试用（2C2G 档）。拿它把 `deploy.sh` 跑一遍，验证整套流程能通，到期前把数据拿回来。

适合：想在买之前先确认「这套脚本在我这儿真能跑通」。

## 方案 D：完全不花钱、连域名也不要

用 **Tailscale Funnel**，免费给你一个 `https://机器名.xxxx.ts.net` 的 HTTPS 域名：

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
sudo tailscale funnel 3000     # 直接把本机 3000 暴露成公网 HTTPS
```

- 优点：DNS、证书、穿透全免费，不用域名、不用备案
- 缺点：域名是 `*.ts.net`，不好记、不像自己的站；国内访问速度一般
- 适合：先给自己和几个朋友看，等确定要长期做再买域名

## 哪些免费平台**不行**（别浪费时间）

| 平台 | 为什么不行 |
|---|---|
| Vercel / Netlify | 函数文件系统只读，`content/` 和 `public/` 写不进去，后台上传必 500 |
| Cloudflare Workers / Pages | 同上，且没有 `ffmpeg`。要用得把存储换成 R2 + D1，是一次重构 |
| Render 免费层 | 15 分钟无访问就休眠，且没有持久磁盘 |
| Railway / Fly.io | 免费层已取消或只剩试用额度 |
| 各类「免费虚拟主机」 | 不给 Node 运行时，只能跑 PHP/静态 |

## 我的建议

1. **今天**：方案 A 上线，先把站跑在公网上，验证真实访问。
2. **这周有空**：试方案 B，抢到 ARM 实例就把 A 迁过去（`rsync` 三样数据 + 改 DNS，半小时）。
3. **确定要长期做**：再考虑 ¥24/月 的香港轻量——每月 24 块换「不用管电、不用管网、不会休眠」，值。

不管走哪条，上线前都要做同一件事：**换掉 `.env` 里的 `JWT_SECRET` 和 `ADMIN_PASSWORD`**。三个方案都会把后台暴露在公网上，这一步省不得。
