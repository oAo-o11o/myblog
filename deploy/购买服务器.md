# 买服务器 · 决策与上手

## 一句话

默认买 **香港轻量 2 核 2G**（¥24–40/月，免备案，今天买今天上）。
要国内秒开且愿意等备案，买 **国内轻量 2C2G + ICP 备案**（学生机 ¥9.9/月）。

## 为什么是这个配置

| 你的站的实际情况 | 结论 |
|---|---|
| 单进程 Node，文件系统当数据库，没有数据库 | 1 核都够，2 核是为了构建时舒服 |
| `next build` 峰值要 1G 上下内存 | **2G 内存 + 2G swap** 才稳，1G 机器会 OOM |
| 视频上传要调 `ffmpeg` | 必须是能 SSH、能装系统包的 VPS |
| 原图一张 8MB，媒体会慢慢长 | 磁盘 40G 起 |
| 访问者主要在国内 | 香港/新加坡 40–90ms，够用 |

**不要买**：虚拟主机、容器云「开发环境」、Serverless 托管（不能写磁盘、不能装 ffmpeg、文件系统只读）。
**不要买**：1G 内存的入门款（构建直接失败，加 swap 也只是勉强）。

## 买的时候避开 5 个坑

1. **带宽看两个数**：峰值带宽（30M）+ 月流量（1T 左右）。只写「不限流量」又给小带宽的，视频首访会卡。
2. **系统选 Ubuntu 24.04 或 22.04**。别选 CentOS 7（软件源过期）、别选带宝塔面板的镜像（白吃 300M 内存）。
3. **必须能 root + SSH**。要网页版「一键部署」才能上网站的，直接排除。
4. **磁盘 40G 起**。你现在 `public/` 已经 9MB，原图不压缩的话很快见底。
5. **先月付试一个月**，别被「3 年 2 折」锁死。

## 买完 10 分钟（照着敲）

```bash
# 1) 初始化系统（把 deploy/bootstrap.sh 传上去，或直接 scp）
scp deploy/bootstrap.sh root@你的IP:/root/
ssh root@你的IP 'bash /root/bootstrap.sh'
#   它会装好：ffmpeg、nginx、ufw、Node 22、pm2、2G swap、目录、防火墙

# 2) 本地推代码（自动 npm ci + build + pm2 重启）
SERVER=root@你的IP bash deploy/deploy.sh

# 3) 配密钥（这一步不做，前面白干）
ssh root@你的IP
cd /opt/myblog/app
cp .env.example .env
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"   # 新的 JWT_SECRET
nano .env      # 填 JWT_SECRET / ADMIN_USERNAME / ADMIN_PASSWORD（12 位以上）

# 4) 起服务
npm ci && npm run build
pm2 start deploy/ecosystem.config.js && pm2 save && pm2 startup

# 5) 反代 + HTTPS
cp deploy/nginx.conf /etc/nginx/conf.d/cyberlog.conf
sed -i 's/shidagu.online/你的域名/g' /etc/nginx/conf.d/cyberlog.conf
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名 -d www.你的域名
```

## 首次部署要单独搬的三样东西

`deploy.sh` 故意排除了这三样（避免你在服务器上改的内容被本地覆盖）：

```bash
rsync -avz content/posts/            root@你的IP:/opt/myblog/app/content/posts/
rsync -avz content/site.json         root@你的IP:/opt/myblog/app/content/
rsync -avz public/photos public/videos root@你的IP:/opt/myblog/app/public/
```

以后在后台写的内容只存在服务器上，本地不要覆盖它。

## 上线验收

```bash
# 本地
$env:BASE="https://你的域名"; node scripts/verify.mjs
```

27 项全绿 + 浏览器打开首页看着正常，就算上线成功。

## 每天要跑的

```bash
# 备份（在服务器 crontab 里）
chmod +x deploy/backup.sh
10 3 * * * /opt/myblog/app/deploy/backup.sh >> /var/log/cyberlog/backup.log 2>&1
```

备份内容只有四样：`content/`、`public/photos/`、`public/videos/`、`.env`。恢复就是解压 + `pm2 restart cyberlog`。
